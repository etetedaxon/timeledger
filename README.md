# TimeLedger PDF Reader

PDF-first reader with IndexedDB-backed PDF storage and PDF.js worker retry using fresh byte buffers. Includes selectable text reflow with adjustable bold-leading transformation, standard/large/reduced-clutter/high-contrast/custom modes, font family, font size, letter spacing, word spacing, line spacing, paragraph spacing and background settings. Also includes bookmarks, saved text highlights visibly marked in reflow mode, notes, folders, unique-page progress, reading-session duration with 10-second checkpoints and pause while the browser tab is hidden, and JSON export of reading data.

Existing localStorage PDF library data is migrated where possible. Email entry is a local browser profile, not verified passwordless authentication. PDFs stay in this browser. The future AI learning assistant is not included. Scanned/image-only PDFs need OCR and cannot be text-reflowed in this version.
