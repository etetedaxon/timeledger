# TimeLedger PDF Reader

PDF-first reader with IndexedDB-backed document storage, PDF.js worker fallback, PDF text extraction and reflow modes. Bold-leading mode transforms the extracted text and bolds an adjustable number of initial letters. Also includes standard/large/reduced-clutter/high-contrast modes, font and spacing controls, bookmarks, saved text highlights, notes, folders, unique-page progress, reading session duration with 10-second checkpoints, and JSON export of reading data.

The old prototype localStorage library is migrated to IndexedDB where possible. Email entry is a local browser profile, not verified passwordless authentication. PDFs remain on this device. The later AI learning assistant is intentionally not included. Scanned/image-only PDFs require OCR and cannot be reflowed in this version.
