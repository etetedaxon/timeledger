# TimeLedger PDF Reader

PDF-first reader with IndexedDB-backed PDF storage, PDF.js worker retry using fresh byte buffers, selectable text reflow and adjustable bold-leading transformation. Includes standard, large-text, reduced-clutter and high-contrast modes; font and spacing settings; bookmarks; saved text highlights visibly marked in reflow mode; notes; folders; unique-page progress; reading sessions persisted every 10 seconds and paused while the browser tab is hidden; and JSON export of reading data.

The prior localStorage PDF library is migrated where possible. Email entry is a local browser profile, not verified passwordless authentication. PDFs remain in this browser. The later AI learning assistant is not included. Scanned/image-only PDFs need OCR and cannot yet be text-reflowed.
